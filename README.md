# Laiza — public pages

The user guide and privacy policy for **Laiza**, an offline-first ebook and fanfiction
reader for Android.

Served by GitHub Pages:

| Page | URL |
|---|---|
| How Laiza works | <https://jmocon.github.io/laiza-public/> |
| Privacy policy | <https://jmocon.github.io/laiza-public/privacy.html> |

Both are plain static HTML with one shared stylesheet — no build step, no Jekyll, no
external requests. `.nojekyll` tells Pages to serve them as they are.

The app's source lives in a separate private repository.
